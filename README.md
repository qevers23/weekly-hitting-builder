# Weekly Hitting Template

A blank weekly hitting calendar a coaching staff fills in themselves.

**Use it:** https://qevers23.github.io/weekly-hitting-builder/

Type your own day focus, phase rotation, cage stations, drills, and swing counts into the
sheet. Set how many cages you have, turn days on and off for a five- or six-day week, and
add or remove drills in any station. Save as many templates as you want under their own
names, switch between them, and print the finished sheet or save it as a PDF.

A `College Fall - 2 Cage` example ships with it. Duplicate that and edit the copy rather
than starting from an empty sheet.

Templates save in your own browser on your own machine -- nothing is uploaded and nobody
else sees what you type. Clearing your browser data clears your templates, so save a PDF of
any template you want to keep or hand to another coach.

Single file, no build step. `index.html` is the whole thing.
